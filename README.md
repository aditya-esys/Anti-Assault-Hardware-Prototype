# Anti-Assault-Hardware-Prototype
A proof-of-concept hardware prototype for a personal self-defense electro-pulse device focused on women's safety. Built using a high-voltage boost module, TP4056, and 3.7V Li-ion battery.

## Problem Statement & Objective
This project aims to build a cost-effective, lightweight, and easily concealable self-defense tool focused on women's safety. 

## Hardware Integration & Form Factor
* **Power Source:** 3.7V Lithium-ion battery.
* **Charging:** Integrated TP4056 module for universal micro-USB charging.
* **Core Component:** High-voltage step-up boost converter module.
* **Enclosure:** Housed in a custom PVC pipe to ensure portability, an ergonomic grip, and quick accessibility during emergencies.

## Deterrent Mechanism
The device generates a high-voltage electrical arc. The bright flash and loud sparking sound are designed to act as a strong deterrent against potential attackers.

**Note:** *This is a proof-of-concept prototype built strictly for social innovation and educational purposes. Strict insulation and safety protocols were followed during assembly and testing.*
